Citrea is a ZK-rollup that settles on Bitcoin. Each batch requires two L1 transactions: a commitment (state root posted by the sequencer) and a proof (ZK proof verifying the state transition). This dashboard tracks every batch — transaction volume, gas usage, and the Bitcoin fees for both commitments and proofs.

Network Overview
